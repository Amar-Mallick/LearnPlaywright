# VS Code Shortcuts for Mac

## General
- `Cmd + Shift + P` — Command Palette
- `Cmd + P` — Quick Open, Go to File
- `Cmd + Shift + N` — New window
- `Cmd + W` — Close window
- `Cmd + ,` — User Settings
- `Ctrl + \`` — Toggle Terminal

## Editing
- `Cmd + C` — Copy
- `Cmd + X` — Cut
- `Cmd + V` — Paste
- `Cmd + Z` — Undo
- `Cmd + Shift + Z` — Redo
- `Cmd + Shift + K` — Delete Line
- `Cmd + Enter` — Insert line below
- `Cmd + Shift + Enter` — Insert line above
- `Option + Up` — Move line up
- `Option + Down` — Move line down
- `Option + Shift + Up` — Copy line up
- `Option + Shift + Down` — Copy line down
- `Cmd + D` — Add selection to next Find match
- `Cmd + U` — Undo last cursor operation
- `Option + Click` — Insert cursor
- `Option + Cmd + Up` — Insert cursor above
- `Option + Cmd + Down` — Insert cursor below
- `Cmd + /` — Toggle line comment
- `Option + Shift + A` — Toggle block comment
- `Option + Z` — Toggle word wrap

## Navigation
- `Cmd + T` — Show all Symbols
- `Ctrl + G` — Go to Line
- `Cmd + P` — Go to File
- `Cmd + Shift + O` — Go to Symbol
- `Cmd + Shift + M` — Show Problems panel
- `F8` — Go to next error or warning
- `Shift + F8` — Go to previous error or warning
- `Ctrl + -` — Navigate back
- `Ctrl + Shift + -` — Navigate forward
- `Cmd + Shift + \` — Go to matching bracket

## Search & Replace
- `Cmd + F` — Find
- `Cmd + Option + F` — Find & Replace
- `Cmd + G` — Find next
- `Cmd + Shift + G` — Find previous
- `Cmd + Shift + F` — Find in files
- `Cmd + Shift + H` — Replace in files

## Multi-Cursor & Selection
- `Option + Cmd + Down` — Insert cursor below
- `Option + Cmd + Up` — Insert cursor above
- `Cmd + Shift + L` — Select all occurrences of current selection
- `Cmd + F2` — Select all occurrences of current word
- `Ctrl + Shift + Cmd + Left` — Expand selection
- `Ctrl + Shift + Cmd + Right` — Shrink selection

## Editor / View
- `Cmd + B` — Toggle Sidebar
- `Cmd + Shift + B` — Toggle Primary Sidebar visibility
- `Cmd + J` — Toggle Panel
- `Cmd + K V` — Open Markdown preview to the side
- `Cmd + Shift + V` — Open Markdown preview
- `Cmd + K Z` — Zen Mode
- `Cmd + =` — Zoom in
- `Cmd + -` — Zoom out
- `Cmd + Num` — Focus into editor group 1/2/3

## Debug
- `F5` — Start Debugging
- `Shift + F5` — Stop Debugging
- `Cmd + F5` — Start Without Debugging
- `F9` — Toggle Breakpoint
- `F10` — Step Over
- `F11` — Step Into
- `Shift + F11` — Step Out

## Integrated Terminal
- `Ctrl + \`` — Show integrated terminal
- `Cmd + Shift + \`` — Create new terminal
- `Ctrl + Shift + 5` — Split terminal
- `Cmd + Up` — Scroll up
- `Cmd + Down` — Scroll down
- `Cmd + Home` — Scroll to top
- `Cmd + End` — Scroll to bottom

## Tabs & Files
- `Cmd + W` — Close tab
- `Cmd + Shift + T` — Reopen closed tab
- `Cmd + Tab` — Switch between open tabs
- `Cmd + N` — New file
- `Cmd + O` — Open file
- `Cmd + S` — Save
- `Cmd + Shift + S` — Save As
- `Cmd + Alt + S` — Save All

## Extensions
- `Cmd + Shift + X` — Extensions view
- `Cmd + Shift + U` — Output panel

## Git
- `Ctrl + Shift + G` — Source Control
- `Cmd + Enter` — Commit (when in Source Control input)
- `Cmd + Shift + P` then `Git: ` — Access all Git commands
