# VS Code Shortcuts for Windows

## General
- `Ctrl + Shift + P` — Command Palette
- `Ctrl + P` — Quick Open, Go to File
- `Ctrl + Shift + N` — New window
- `Ctrl + W` — Close window
- `Ctrl + ,` — User Settings
- `Ctrl + \`` — Toggle Terminal

## Editing
- `Ctrl + C` — Copy
- `Ctrl + X` — Cut
- `Ctrl + V` — Paste
- `Ctrl + Z` — Undo
- `Ctrl + Shift + Z` — Redo
- `Ctrl + Shift + K` — Delete Line
- `Ctrl + Enter` — Insert line below
- `Ctrl + Shift + Enter` — Insert line above
- `Alt + Up` — Move line up
- `Alt + Down` — Move line down
- `Alt + Shift + Up` — Copy line up
- `Alt + Shift + Down` — Copy line down
- `Ctrl + D` — Add selection to next Find match
- `Ctrl + U` — Undo last cursor operation
- `Alt + Click` — Insert cursor
- `Alt + Ctrl + Up` — Insert cursor above
- `Alt + Ctrl + Down` — Insert cursor below
- `Ctrl + /` — Toggle line comment
- `Shift + Alt + A` — Toggle block comment
- `Alt + Z` — Toggle word wrap

## Navigation
- `Ctrl + T` — Show all Symbols
- `Ctrl + G` — Go to Line
- `Ctrl + P` — Go to File
- `Ctrl + Shift + O` — Go to Symbol
- `Ctrl + Shift + M` — Show Problems panel
- `F8` — Go to next error or warning
- `Shift + F8` — Go to previous error or warning
- `Ctrl + Alt + -` — Navigate back
- `Ctrl + Shift + -` — Navigate forward
- `Ctrl + Shift + \` — Go to matching bracket

## Search & Replace
- `Ctrl + F` — Find
- `Ctrl + H` — Find & Replace
- `F3` — Find next
- `Shift + F3` — Find previous
- `Ctrl + Shift + F` — Find in files
- `Ctrl + Shift + H` — Replace in files

## Multi-Cursor & Selection
- `Alt + Ctrl + Down` — Insert cursor below
- `Alt + Ctrl + Up` — Insert cursor above
- `Ctrl + Shift + L` — Select all occurrences of current selection
- `Ctrl + F2` — Select all occurrences of current word
- `Shift + Alt + Right` — Expand selection
- `Shift + Alt + Left` — Shrink selection

## Editor / View
- `Ctrl + B` — Toggle Sidebar
- `Ctrl + Shift + B` — Toggle Primary Sidebar visibility
- `Ctrl + J` — Toggle Panel
- `Ctrl + K V` — Open Markdown preview to the side
- `Ctrl + Shift + V` — Open Markdown preview
- `Ctrl + K Z` — Zen Mode
- `Ctrl + =` — Zoom in
- `Ctrl + -` — Zoom out
- `Ctrl + Num` — Focus into editor group 1/2/3

## Debug
- `F5` — Start Debugging
- `Shift + F5` — Stop Debugging
- `Ctrl + F5` — Start Without Debugging
- `F9` — Toggle Breakpoint
- `F10` — Step Over
- `F11` — Step Into
- `Shift + F11` — Step Out

## Integrated Terminal
- `Ctrl + \`` — Show integrated terminal
- `Ctrl + Shift + \`` — Create new terminal
- `Ctrl + Shift + 5` — Split terminal
- `Ctrl + Up` — Scroll up
- `Ctrl + Down` — Scroll down
- `Ctrl + Home` — Scroll to top
- `Ctrl + End` — Scroll to bottom

## Tabs & Files
- `Ctrl + W` — Close tab
- `Ctrl + Shift + T` — Reopen closed tab
- `Ctrl + Tab` — Switch between open tabs
- `Ctrl + N` — New file
- `Ctrl + O` — Open file
- `Ctrl + S` — Save
- `Ctrl + Shift + S` — Save As
- `Ctrl + Alt + S` — Save All

## Extensions
- `Ctrl + Shift + X` — Extensions view
- `Ctrl + Shift + U` — Output panel

## Git
- `Ctrl + Shift + G` — Source Control
- `Ctrl + Enter` — Commit (when in Source Control input)
- `Ctrl + Shift + P` then `Git: ` — Access all Git commands
